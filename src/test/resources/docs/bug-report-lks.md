4. Посмотреть на текст "Найдено X результатов"

- Может привести к пропуску важных отчетов

**Рекомендации**:
- Исправить логику подсчета отчетов
- Убедиться, что счетчик показывает реальное количество
- Синхронизировать данные между UI компонентами
